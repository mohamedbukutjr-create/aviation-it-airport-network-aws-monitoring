# Aviation IT Portfolio: Airport Network Support Projects

This repository contains focused aviation IT networking projects designed for IT Support, NOC, Network Support, Airport IT Support, Junior Network Administrator, and Operational IT Analyst roles in Toronto/GTA.

## Projects

### Project 1 — EVE-NG Airport VLAN Network Design

A realistic airport/airline branch network lab with VLAN segmentation for:

- Check-in counters
- Gate/boarding devices
- Baggage scanners and bag-tag printers
- Airport operations/control-centre users
- IT management
- Guest Wi-Fi
- Server/DNS/application services

The project includes Cisco IOS-style configs, ACLs, DHCP, DNS design, routing, Wi-Fi troubleshooting, mock airline IT incident tickets, and a baggage scanner/printer runbook.

**Open project:** [PROJECT-1-EVE-NG-Airport-Network](PROJECT-1-EVE-NG-Airport-Network/README.md)

### Project 2 — Airport NOC Network Support Project

A portfolio-ready Airport NOC troubleshooting and network support project focused on VLANs, trunks, router-on-a-stick, DHCP, ACL segmentation, vendor DMZ controls, and a real troubleshooting case where the VENDOR_DMZ PC could not ping its default gateway because of ACL order.

**Open project:** [Airport NOC Network Support Project](PROJECT-2-Airport-NOC-Network-Support-Project/README.md)
