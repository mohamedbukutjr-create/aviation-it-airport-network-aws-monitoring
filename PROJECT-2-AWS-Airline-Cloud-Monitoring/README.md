# Project 2: AWS Airline Cloud Monitoring Dashboard

## Objective
Build a cloud monitoring design for a mock airline operations application that supports check-in, baggage events, and operations dashboards.

## Architecture
- VPC with public and private subnets
- EC2 mock app server
- CloudWatch log group
- CloudWatch dashboard
- CPU/status alarms
- SNS topic for incident alerts
- IAM least-privilege concepts
- Security group rules
- Optional S3 bucket for static runbooks/screenshots

## Career Skills Demonstrated
- AWS VPC design
- CloudWatch monitoring and dashboards
- SNS alerting
- IAM least privilege
- Security groups
- Incident response documentation
- Cloud troubleshooting
- GitHub portfolio documentation
