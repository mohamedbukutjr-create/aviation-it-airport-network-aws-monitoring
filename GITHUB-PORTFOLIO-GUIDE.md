## Screenshot Checklist
Add screenshots under `screenshots/`:
- EVE-NG topology
- `show vlan brief`
- `show interfaces trunk`
- `show ip dhcp binding`
- `show access-lists`
- Successful ping tests
- Failed guest-to-internal test
- AWS VPC page
- CloudWatch dashboard
- CloudWatch alarm
- SNS topic
- Terraform plan/apply output
